# K8S Deployment Manifests

## Overview
This repository contains Kubernetes manifests for deploying core platform services and supporting infrastructure.

## What is included
- **Deployments** for application and infrastructure components.
- **Services** (ClusterIP/NodePort) for internal and external communication.
- **Ingress** configuration for HTTP routing.
- **Persistent storage** resources (PVC) for stateful workloads.
- **Messaging and data components** such as RabbitMQ and MSSQL manifests.

## Repository purpose
Use these manifests as a baseline for local development, testing, or as a starting point for environment-specific Kubernetes deployments.
